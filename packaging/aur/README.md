# Publishing Tandem to the AUR

Tandem ships as a `.deb` (Debian / Ubuntu / Zorin) and as a distro-agnostic
tarball (every other Linux). This directory holds the recipe for a **native
Arch package**, so an Arch user can install Tandem with `pacman` or an AUR
helper instead of unpacking a tarball by hand.

## What is here

- **`PKGBUILD`** — generated by `build.py` from the same LAYOUT and the same
  version as the `.deb`, so it cannot drift. It is a build artifact
  (git-ignored); run `python3 build.py` to (re)create it. It downloads the
  release's generic tarball, checks it against the `sha256sums` `build.py`
  computed, and installs it with the bundle's own `install.sh`
  (`DESTDIR="$pkgdir"`) — the exact same files the `.deb` and the tarball lay
  down, from one copy path.
- **`tandem.install`** — the pacman scriptlet: refreshes the desktop/MIME/icon
  caches and prints the same install notice the `.deb` shows, in the machine's
  language.

## Publishing (the one manual step — owner only)

Publishing to the AUR needs an AUR account with an SSH key registered to it.
That is the single credential in this chain, and it stays with the owner: it
never touches this repository or an agent session — the same shape as
connecting the Vercel Blob store for the community list.

```sh
python3 build.py                         # writes packaging/aur/PKGBUILD
git clone ssh://aur@aur.archlinux.org/tandem.git aur-tandem
cd aur-tandem
cp ../packaging/aur/PKGBUILD ../packaging/aur/tandem.install .
makepkg --printsrcinfo > .SRCINFO        # the AUR requires this file
git add PKGBUILD tandem.install .SRCINFO
git commit -m "tandem <version>"
git push
```

Each later release is the same: copy the new `PKGBUILD`, regenerate `.SRCINFO`,
commit, push. The release workflow also attaches `PKGBUILD` and `tandem.install`
to the GitHub release, so they can be fetched from there instead of a local
build.

## Testing it without publishing

```sh
python3 build.py                         # writes PKGBUILD + the generic tarball
mkdir -p /tmp/aur && cp packaging/aur/PKGBUILD packaging/aur/tandem.install /tmp/aur/
cp tandem_*_generic.tar.gz /tmp/aur/     # so makepkg finds it as a local source
cd /tmp/aur
# point source at the local tarball (no release URL yet), then build + install:
sed -i "s#.*::.*#source=(tandem_$(python3 -c 'print(open(\"PKGBUILD\").read().split(\"pkgver=\")[1].split()[0])')_generic.tar.gz)#" PKGBUILD
makepkg -si
```

On a non-Arch machine, do the same inside an `archlinux` container with
`base-devel` installed.
