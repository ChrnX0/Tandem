# Tandem - catálogo de mensagens, português do Brasil.
#
# ESTE É O ORIGINAL. Toda outra tradução responde a este arquivo, e toda chave
# que falte numa tradução cai aqui. Uma frase perdida numa edição vira uma
# frase em português, nunca uma tela vazia.
#
# FORMATO
#   @chave        abre uma mensagem; tudo até a próxima @chave é o texto
#   {1} {2} {3}   onde entram os pedaços variáveis (caminho, nome, número)
#   # no começo   comentário, quando está fora de uma mensagem
#   \@ \#         para uma mensagem que precisa começar com @ ou #
#
# Este arquivo NUNCA é executado. Cifrão, crase e $(...) aqui dentro são texto
# e continuam texto. Você não precisa saber programar para traduzir.
#
# REVISADO=sim  (é o idioma em que o programa foi escrito)
